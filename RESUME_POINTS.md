# Resume Bullet Points

- Developed a full-stack Brain Tumor Analysis System using React, Tailwind CSS, FastAPI, and TensorFlow.
- Implemented medical image classification and segmentation pipelines for brain tumor detection and subtype prediction.
- Built a responsive frontend dashboard with analysis, batch processing, history tracking, and QR sharing features.
- Designed REST API endpoints for model inference and PDF medical report generation using ReportLab.
- Preprocessed CT/MRI images with OpenCV and Pillow to support reliable model inference.
- Integrated browser-based history persistence using `localStorage` for offline session recall.
- Supported model evaluation and training scripts for binary detection, tumor type classification, and segmentation.
- Demonstrated local deployment with `uvicorn` and Vite for backend and frontend development.
